# 🏠 Interior Design VR - Web Platform (Django)

Plataforma web desarrollada en Django como parte de un proyecto de titulación enfocado en diseño de interiores con realidad virtual. Esta aplicación actúa como el sistema central de gestión para administradores, diseñadores y clientes.

## 🚀 Descripción

El sistema permite gestionar espacios interiores previamente escaneados o generados en un entorno de realidad virtual, facilitando la personalización de ambientes mediante la selección y configuración de mobiliario.

La plataforma web funciona como backend administrativo y panel de control, permitiendo organizar, visualizar y administrar todos los recursos utilizados en la experiencia VR.

## ⚙️ Funcionalidades principales

- CRUD completo de mobiliario (creación, edición, eliminación)
- Gestión de usuarios (administradores, diseñadores, clientes)
- Panel administrativo para control de contenido
- Integración con entorno de realidad virtual
- Organización de espacios interiores digitalizados

## 🧱 Tecnologías utilizadas

- Django (Backend)
- Python
- SQLite / PostgreSQL
- HTML, CSS, JavaScript

## 🎯 Objetivo

Centralizar la gestión de datos y recursos para una solución de diseño de interiores basada en realidad virtual, permitiendo una experiencia más interactiva, organizada y escalable.

## 📌 Estado

Proyecto académico finalizado como parte de titulación universitaria.
